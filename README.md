# EV Battery Quality Classification Using AI

## Project Description
This project uses deep learning to classify electric vehicle battery quality based on manufacturing data.

## Dataset
EV Battery QC Dataset (Synthetic)

## Objective
To classify battery quality into:
- Grade A
- Grade B
- Scrap

## Tools
- Python
- TensorFlow
- Scikit-learn
- Pandas
- Matplotlib

## Methods
1 Data preprocessing  
2 Feature selection  
3 Deep learning model  
4 Model evaluation  

## Target Variable
QC_Grade
